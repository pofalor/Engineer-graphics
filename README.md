# Инженерная графика

Работы по инженерной и компьютерной графике, выполненные в **КОМПАС-3D**.

## Содержание

| Работа | Файлы | Описание |
|--------|-------|----------|
| laba_5 | `Деталь.m3d`, `Деталь2.m3d`, `Сечение.m3d`, `Сечение.cdw`, `Проекционное черчение _ МИГ .202018.000.cdw` | Проекционное черчение: трёхмерные модели деталей и чертежи с разрезами и сечениями |
| laba_6 | `laba_6.m3d`, `Пробка.cdw` | Модель и рабочий чертёж детали «Пробка» |
| — | [фланец.cdw](фланец.cdw) | Чертёж фланца |

## Форматы файлов

* `.m3d` — трёхмерная модель детали КОМПАС-3D;
* `.cdw` — чертёж КОМПАС-3D;
* `.bak` — резервные копии, создаваемые самим КОМПАСом (исключены через [.gitignore](.gitignore)).

Для просмотра и редактирования нужен КОМПАС-3D (подойдёт бесплатная учебная версия).
